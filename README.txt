CARA PAKAI
1. Buka folder ini di VS Code (File > Open Folder).
2. Install ekstensi "Live Server", klik kanan index.html > Open with Live Server.
3. Isi SEMUA konten di data.js. Tidak perlu edit index.html.

LETAK FILE
images/foto.png          -> foto profil (PNG transparan / background dihapus paling bagus)
images/projek1-5.jpg     -> screenshot tiap projek
certificates/*.pdf       -> PDF sertifikat (nama file harus sama dengan di data.js)
Link website projek      -> kolom "link" di data.js
Warna utama              -> variabel --red di atas style.css
